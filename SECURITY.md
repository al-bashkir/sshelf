# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately on GitHub: open the **Security** tab and click
**Report a vulnerability**, or go to
https://github.com/al-bashkir/sshelf/security/advisories/new.

Include the sshelf version, your OS, and the steps to reproduce the problem.

## Supported versions

Only the latest release gets security fixes.
